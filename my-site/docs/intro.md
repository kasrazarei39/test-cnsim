# CNSim Documentation

Welcome to the CNSim project documentation. This site contains technical documentation, Architecture Decision Records (ADRs), and other important project information.

## Getting Started

This documentation is built with Docusaurus and organized into several sections:

- **Architecture Decision Records**: Important architectural decisions made during development
- **Tutorial**: Step-by-step guides for using the system
- **API Documentation**: Technical reference materials

## Architecture Decision Records

Architecture Decision Records (ADRs) document important architectural decisions made during the development of this project. They provide context for why certain technical choices were made and help future developers understand the reasoning behind the architecture.

### ADR Structure

Each ADR follows a standard format:
- **Status**: Current state of the decision (Proposed, Accepted, Rejected, etc.)
- **Context**: The issue motivating the decision
- **Decision**: What was decided
- **Consequences**: Positive and negative outcomes
- **Alternatives**: Other options considered

### Creating New ADRs

To create a new ADR:
1. Copy the [ADR Template](adrs/0000-template.md)
2. Assign the next sequential number
3. Fill in all sections completely
4. Submit for review

## Navigation

Use the sidebar to navigate between different sections of the documentation. The ADRs are organized chronologically by their assigned numbers.
